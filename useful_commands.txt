ON LINUX to allow the communication to OCEAN OPTICS HL-2000-HP-232 halogen lamp

1. Update the usb .rules file located at /etc/udev/rules.d/ by running:

sudo nano /etc/udev/rules.d/99-usbusers.rules

2. Add the following rule to the file:

KERNEL=="ttyUSB*", MODE="0666", GROUP=="dialout"

3. Save modification by pressing Ctrl + O

4. Leave the text editor with Ctrl + X

5. Apply new rules:

sudo udevadm control --reload-rules && sudo udevadm trigger
